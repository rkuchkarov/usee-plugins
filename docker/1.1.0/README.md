# Docker (docker)

Плагин Usee: статус демона Docker и контейнеры (CPU/RAM) на дисплее. SDK 8.

## Как это работает
Docker Engine API — это HTTP/1.1. На Windows/Docker Desktop он слушает именованный
пайп `\\.\pipe\docker_engine` — плагин обращается к нему обычным
`fetch("pipe://docker_engine/…")` (разрешение `pipe`; своего HTTP-клиента в плагине
больше нет). Если задан TCP-адрес демона — обычный `http://`.

Опрос раз в N секунд:
- `GET /containers/json?all=1` — список контейнеров и их состояние;
- `GET /containers/{id}/stats?stream=false` — CPU/RAM по запущенным, **только если
  карточка «контейнеры» размещена** (`ctx.cards.placed()`): сбор идёт ~секунду на
  контейнер, и для неразмещённой карточки его не делают.

## Карточки
- **status «Docker»** — встроенная иконка `containers` + `N / M контейнеров`, бейдж =
  число запущенных; «демон недоступен», если Docker не запущен (число тогда не
  публикуется — не выдумываем 0).
- **meters «контейнеры»** — топ-4 контейнера по CPU % или RAM % (настройка).

Какие карточки показывать — раскладка сцен Usee, ширина — настройки карточки Usee.

## Настройки
| Ключ | Тип | Назначение |
|------|-----|-----------|
| `endpoint` | string | TCP-адрес демона (напр. `127.0.0.1:2375`). **Пусто = именованный пайп** (рекомендуется). Через TCP — только если включён незащищённый эндпоинт демона |
| `metric` | select | что в мини-барах: `cpu` (по умолчанию) или `mem` |
| `label` | string | подпись статус-карточки |
| `intervalSec` | number | период опроса, 2–300 с (по умолчанию 5) |

## Права
```json
"permissions": { "pipe": ["docker_engine"], "net": ["setting:endpoint"] }
```
`pipe` — HTTP к пайпу движка (по умолчанию). `net:["setting:endpoint"]` — TCP-режим
разрешает только тот хост, что указан в настройке `endpoint`.

## Требования
- **Агент с SDK 8** (Usee ≥ 1.5.0).
- **Windows + Docker Desktop** (пайп `docker_engine` поднимает он сам). Либо
  включённый TCP-эндпоинт демона и заполненная настройка `endpoint`.
- Unix-сокет `/var/run/docker.sock` не поддерживается (агент — Windows).

## Локальная проверка
Агент → «Плагины» → **＋ «Плагин из папки разработки…»** → эта папка. Или
скопировать `manifest.json` + `plugin.js` в
`%AppData%\PcMonitorAgent\plugins\docker\1.1.0\`. При запущенном Docker Desktop
карточки появятся сразу; иначе статус покажет «демон недоступен».
