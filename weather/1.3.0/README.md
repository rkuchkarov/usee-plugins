# Погода (weather)

Плагин Usee: текущая погода и прогноз по городу через [Open-Meteo](https://open-meteo.com)
— бесплатный API **без ключа**. SDK 11.

## Карточки
- **gauge «температура»** — текущая t° как `number` со шкалой-заливкой
  (метрика −30…45 °C, имперская −20…115 °F).
- **status «условия»** — встроенная иконка погоды Usee (`sun`, `star` ночью, `partly`, `cloud`,
  `fog`, `rain`, `snow`, `storm`) + описание (line1), «ощущается / влажность / давление /
  ветер» (line2 с адаптивными вариантами по ширине экрана), t° в бейдже.
- **status «прогноз»** — обзор на сегодня: иконка прогноза, описание погоды (line1),
  диапазон «ночью t° · днём t° · осадки» (line2), макс. температура в бейдже.

Плагин публикует все карточки; **какие показывать и где** — раскладка сцен Usee,
**ширина** — настройки карточки Usee (как у встроенных).

## Города и координаты (экземпляры, 1.2.0+)
Город — у экземпляра: «Карточки» → «＋ Город». У каждого города свои карточки
(«Погода · температура · Новосибирск»…), первый город переехал из прежней настройки
плагина сам.

В поле `city` можно:
1. Выбрать город через live-автокомплит на ввод (геокодинг Open-Meteo, провайдер `searchCity`).
2. Ввести координаты напрямую в формате `lat, lon` (например, `55.75, 37.62`): в этом случае геокодинг пропускается.

Найденные координаты кэшируются в постоянном хранилище (`storage`), поэтому при повторных
запусках плагин не тратит время и сеть на повторный геокодинг.

Подпись на приборе задаёт человек в окне карточки (по умолчанию — имя города или координаты);
своей настройки «Подпись» у плагина нет.

## Настройки (общие)
| Ключ | Тип | Назначение |
|------|-----|-----------|
| `units` | select | `metric` (°C · м/с, по умолчанию) или `imperial` (°F · mph) |
| `pressureUnit` | select | `mmhg` (мм рт. ст., по умолчанию), `hpa` (гПа / мбар) или `inhg` (inHg) |
| `intervalMin` | number | Период опроса, 1–240 мин (по умолчанию 15); карточки живут 3 периода |

## Права
`net: ["*.open-meteo.com"]` — только геокодинг и прогноз Open-Meteo. Ключей и
секретов нет.

## Данные Open-Meteo
- Геокодинг: `https://geocoding-api.open-meteo.com/v1/search?name=<город>`
- Прогноз: `https://api.open-meteo.com/v1/forecast?...&current=temperature_2m,`
  `apparent_temperature,relative_humidity_2m,is_day,weather_code,pressure_msl,wind_speed_10m,wind_direction_10m&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_sum`;
  не отвечает — тот же запрос на `historical-forecast-api.open-meteo.com` (тот же JSON и коды WMO).
  Хост, который ответил, запоминается (`storage.forecastHost`) — следующий опрос идёт сразу к нему.
  У части провайдеров адреса `api.open-meteo.com` фильтруются целиком.

`weather_code` (WMO) переводится в русское описание и иконку внутри плагина с учетом времени суток (`is_day`).

## Шина значений (сущности)
Плагин объявляет сущности для условий сцен и автоматизаций (`ctx.entities`):
- `weather.temperature`, `weather.apparent_temperature`
- `weather.temp_max`, `weather.temp_min`
- `weather.humidity`, `weather.pressure`
- `weather.wind_speed`, `weather.wind_dir`
- `weather.condition`, `weather.is_day`

## Локальная проверка
Агент → «Плагины» → **＋ «Плагин из папки разработки…»** → эта папка: без
копирования, правка файлов перезапускает плагин сам. Или положить `manifest.json`
и `plugin.js` в `%AppData%\PcMonitorAgent\plugins\weather\1.3.0\`. Без Windows:
`usee-plugin run plugins/weather --set city=Москва --png out/`.
