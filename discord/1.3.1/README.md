# Discord (discord)

Плагин Usee: голосовой канал Discord на экране прибора (ростер участников, индикация «кто говорит» в реальном времени, аватарки). SDK 11.

## Как это работает

Плагин подключается к запущенному десктопному клиенту Discord через локальный Named Pipe IPC (`discord-ipc-0`..`9`).

1. **Рукопожатие и авторизация:**
   - При первом запуске в клиенте Discord появляется всплывающее окно авторизации Usee.
   - Плагин выполняет обмен кода авторизации по протоколу PKCE OAuth S256 (`https://discord.com/api/oauth2/token`).
   - Полученный токен безопасно сохраняется в зашифрованном хранилище хоста (`ctx.secrets`).
2. **События голосового канала:**
   - Плагин подписывается на события выбранного голосового канала: `SPEAKING_START`, `SPEAKING_STOP`, `VOICE_STATE_CREATE`, `VOICE_STATE_UPDATE`, `VOICE_STATE_DELETE`.
   - Индикация говорения обновляется мгновенно через реактивный патч (`immediate: true`), обеспечивая задержку реакции менее 60 мс.
3. **Аватарки:**
   - Аватарки участников загружаются с Discord CDN (`cdn.discordapp.com`) и преобразуются в растровые иконки через хост-пул `ctx.images.toIcon`.
4. **Управление жизненным циклом (SDK 11):**
   - Через `permissions.apps` плагин отслеживает процесс Discord: пока Discord закрыт, плагин не тратит ресурсы на сканирование пайпов и мгновенно активируется при запуске приложения.

## Карточка

| Карточка | Тип | Что отображает |
|---|---|---|
| `voice` | `voice` | Активные участники голосового канала, индикация говорящего рамкой/цветом, аватарки, локальный статус микрофона |

## Настройки

| Ключ | Тип | Назначение |
|---|---|---|
| `notifyJoin` | bool | Уведомлять системным тостом о входе нового участника в голосовой канал (по умолчанию `true`) |

## Права доступа

- `pipe`: доступ к локальному пайпу Discord RPC (`discord-ipc-*`).
- `net`: авторизация на `discord.com` и загрузка аватарок с `cdn.discordapp.com`.
- `notifications`: отправка тостов о подключении участников.
- `apps`: отслеживание статуса процесса Discord.
