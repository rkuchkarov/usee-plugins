# Криптовалюты (crypto)

Плагин Usee: котировки криптовалют в реальном времени через [CoinGecko](https://www.coingecko.com) — бесплатный публичный API **без ключа**. SDK 11.

## Карточки
- **message «котировка» (quote)** — крупная карточка в стиле Советника: название монеты (line1), большая цена с валютой (num/unit), суточное изменение % (num2/unit2), тон (good при росте, problem при падении), диапазон min/max за 24ч (expl) и полоса положения цены между суточным минимумом и максимумом (progress 0–100%).
- **status «тикер» (ticker)** — компактный индикатор: тикер и цена (line1), 24ч изменение с суточными high/low (line2 с вариантами под ширину экрана), бейдж с процентом (зеленый/нейтральный), суточный объем торгов (detail).
- **spark «график 24ч» (chart)** — текущее значение + 24-часовая кривая динамики цен (24 почасовые точки из API, нормализованные 0–255). При ценах выше $30k значение масштабируется в тысячи (k$), чтобы помещаться в 16-битный целочисленный формат прибора.

## Монеты (экземпляры)
Монета настраивается у экземпляра: «Карточки» → «＋ Монета». У каждой монеты свой набор карточек («БИТКОИН (BTC)», «ЭФИРИУМ (ETH)», «СОЛАНА (SOL)»…).

В поле `coin` можно:
1. Выбрать популярную монету из выпадающего списка (BTC, ETH, SOL, TON, BNB, XRP, DOGE, ADA…).
2. Ввести тикер или название на русском/английском («btc», «тон», «эфир», «solana») — плагин сопоставит синоним локально.
3. Ввести любую монету из базы CoinGecko через live-автокомплит на ввод (провайдер `searchCoin`).

Все активные монеты запрашиваются одним пакетным запросом (`coins/markets?ids=...`), что экономит сетевые вызовы и исключает исчерпание лимитов API.

## Настройки (общие)
| Ключ | Тип | Назначение |
|------|-----|-----------|
| `currency` | select | Валюта котировок: `usd` ($), `eur` (€) или `rub` (₽) |
| `intervalMin` | number | Период опроса, 1–60 мин (по умолчанию 2 мин); карточки живут 3 периода |

## Права
`net: ["api.coingecko.com"]` — только котировки и поиск CoinGecko. Локальных команд и секретов нет.

## Шина значений (сущности)
Для каждой монеты плагин объявляет сущности в шине (`ctx.entities`) для условий сцен и автоматизаций:
- `crypto.price` (или `crypto.<id>.price` для дополнительных монет) — текущая цена
- `crypto.change_24h` (или `crypto.<id>.change_24h`) — изменение за сутки в %
- `crypto.high_24h` (или `crypto.<id>.high_24h`) — максимум за 24ч
- `crypto.low_24h` (или `crypto.<id>.low_24h`) — минимум за 24ч
- `crypto.volume` (или `crypto.<id>.volume`) — суточный объем
