# OBS Studio (obs)

Плагин Usee: идёт ли запись и эфир прямо сейчас, какая сцена в программе, метры
самого OBS и состояние микрофона. SDK 8.

## Как это работает

Плагин — **наблюдатель**: в obs-websocket уходят только рукопожатие
(`Hello`/`Identify`) и запросы на чтение. Ни `StartRecord`, ни
`SetCurrentProgramScene`, ни `ToggleInputMute` в коде нет вовсе — управление
начнём писать тогда, когда у прибора появится ввод (сенсорный экран), и граница
тогда видна по самому коду, а не по обещанию.

- **События решают скорость.** `RecordStateChanged`, `StreamStateChanged`,
  `CurrentProgramSceneChanged`, `StudioModeStateChanged`, `InputMuteStateChanged`,
  `CurrentProfileChanged`, `CurrentSceneCollectionChanged`, `ReplayBufferSaved` —
  на них карточки патчатся `immediate` (пол 50 мс), поэтому точка записи
  загорается не «в следующий опрос», а сразу. Подписка — битовой маской категорий
  в `Identify` (`General|Config|Scenes|Inputs|Outputs`): `Transitions`,
  `Filters`, `SceneItems` и тем более высокочастотный `InputVolumeMeters` не
  включаем вовсе.
- **Опрос доносит числа.** Каждый тик: `GetStats` (CPU OBS, память, скипнутые
  кадры, свободно на диске, `activeFps`), `GetRecordStatus`, `GetStreamStatus`,
  `GetCurrentProgramScene`. Реже (сразу после подключения и на событиях `Config`):
  `GetVersion`, `GetStudioModeEnabled`, `GetProfileList`, `GetSceneCollectionList`,
  `GetInputList`, `GetProfileParameter`.
- **Набор запросов спрашивают у OBS, а не знают наперёд.** `GetVersion` отдаёт
  `availableRequests`; чего в этой сборке нет — не спрашиваем. Между obs-websocket
  5.x и 6.x наборы расходятся (например `GetStudioModeEnabled`), а OBS 28 и
  старее говорит на протоколе 4.x — с ним плагин не работает вовсе.
- **Длительность идёт сама между опросами.** OBS отдаёт `outputDuration` на момент
  ответа; дальше счётчик едет по локальным часам, иначе `REC 00:00` менялся бы
  скачками раз в интервал опроса. На паузе счётчик стоит.
- **Битрейта в протоколе нет** — ни в `GetStats`, ни в `GetStreamStatus`. Он дельта
  `outputBytes`: первое измерение появляется только со второго тика, окно
  сглаживания — 60/40, при обрыве обнуляется.
- **Целевой FPS берём из профиля** (`GetProfileParameter` → `fps_den`/`fps_num`):
  в `GetStats` есть только текущий `activeFps`. Не отдали — в статусе нет «цель …»,
  и это честно.
- **Карточка микрофона** ищет вход по имени (по умолчанию `Mic/Aux`): `GetInputList`
  один раз на подключение. Нет такого входа — карточка снимается один раз, и в логе
  перечислены входы, которые OBS назвал сам; угадывать имя по «похожести» не стали.
- **Дорогое — только для размещённого.** Ряд `spark` (точки — сами значения
  кадров/с; при 300 к/с точка не едет, число карточки остаётся настоящим) и опрос
  микрофона делаются, только если карточка стоит в раскладке (`ctx.cards.placed()`).
- **OBS выключен — карточка остаётся.** Иначе «прибор сломался» неотличим от «OBS
  не запущен»: `OBS · нет связи`, бейдж отсутствует, остальные карточки плагина
  сняты. Переподключение — экспоненциально 2→4→…→30 с.
- **Строки режем по байтам прошивки, а не по знакам.** Буферы полей фиксированные
  (§12 ТЗ), а `utf8Copy` (`include/card_slots.h`, `CS_CAP = sizeof поля − 1`) режет
  сверху молча: ни ошибки, ни предупреждения, просто оборванное слово. Кириллица —
  2 байта, поэтому `sec[12]` не вмещает «17,6 Мбит/с»: в ряду остаётся целое
  «18 Мбит», а точное значение — в `footer[48]`. Для профилей и коллекций, которые
  не влезают вместе, показываем то, что влежется целиком, а не обрезок.

## Карточки

| Карточка | Тип | Что на ней |
|---|---|---|
| OBS · эфир | `status` | `REC 12:34` / `LIVE 1:02:11` / `OBS`, сцена второй строкой; бейдж `РЕКОНН` / `ПАУЗА` / `LIVE` / `STUDIO`; четвёртая строка — профиль · коллекция сцен |
| OBS · кадры | `spark` | кадров в секунду + кривая за 90 отсчётов |
| OBS · метры | `meters` | CPU OBS (и память, МБ → ГБ если не влезает), пропущенные кадры (и их доля), конжестия + битрейт целым числом Мбит; футер — свободно на диске · точный битрейт |
| OBS · микрофон | `status` | включён/замутен, уровень в дБ; бейдж `MUTE` |

Тосты: запись пошла / остановлена (+ имя файла), эфир пошёл, эфир теряется
(`critical`), эфир восстановлен, эфир оборвался, реплей сохранён. Отключаются
настройкой `Тосты` → «не слать».

Для шины значений карточки отдают `state` (`recording` / `live` / `idle` /
`offline`, у микрофона `on` / `muted`), `is_on` и `number` — длительность текущего
вывода в секундах. Через `mqtt-bridge` это уезжает в Home Assistant как есть, а
условие «показывать карточку, пока идёт эфир» собирается по `obs.state`.

## Что включить в OBS

OBS 30.2+ ставит obs-websocket сам: **Tools → WebSocket Server Settings → Enable
WebSocket Server** (порт 4455). Если там включён Authentication — тот же пароль
нужно ввести в настройках плагина. Плагин считает строку по алгоритму OBS
(`base64(sha256(base64(sha256(пароль + salt)) + challenge))`) и держит её в
секрете (DPAPI), а не в открытом конфиге.

Соединение — простой `ws://`, без TLS: для OBS на этой машине это не риск, а для
OBS на другой доверие держит канал (локальная сеть, VPN, Tailscale). Галочку
Secure WebSocket (WSS) в настройках obs-websocket плагин не использует — если
включить её, подключение не установится.

По умолчанию плагин ходит на `127.0.0.1`. Сеть разрешена ровно по значению
настройки `host` (`setting:host`) — шире она не открывается. Для OBS на другой
машине укажите его адрес; без пароля на WebSocket-сервере это голый http-уровень
доверия, и плагин тогда не начнёт отказывать — это выбор пользователя, о котором
стоит помнить.

## Настройки

| Ключ | Что |
|---|---|
| `host` / `port` | адрес и порт obs-websocket (по умолчанию `127.0.0.1:4455`) |
| `password` | пароль WebSocket-сервера ( secret, DPAPI) |
| `intervalSec` | интервал опроса чисел, 1–30 с (по умолчанию 2). События не ждут тика |
| `notify` | `outputs` (запись/эфир/обрывы) или `off` |
| `showMic` / `micInput` | карточка микрофона и имя входа в OBS |

## Как проверить без OBS

```bash
bash tools/usee-plugin.sh validate plugins/obs
bash tools/usee-plugin.sh run plugins/obs --set host=127.0.0.1 --set port=4455 \
     --set password=… --place obs --place stats --place fps --place mic --seconds 20
```

В логе видно рукопожатие, версию obs-websocket и каждое изменение карточки.
«нет связи» при незапущенном OBS — ожидаемое поведение, а не ошибка плагина.

## Чего здесь нет намеренно

- Управления: переключение сцен, запись, mute, профили — всё это требует ввода у
  прибора, а его пока нет.
- Превью сцены картинкой (`GetSourceScreenshot`) и мульттивью: картинка 24×24
  ничего не показывает про сцену, а список сцен полезнее текстом.
- VU-метрах микрофона: `InputVolumeMeters` — высокочастотное событие, и на баре
  карточки оно сгорело бы в лимите `immediate`; уровень читаем редко через
  `GetInputVolume`.
- obs-websocket 4.x (OBS 28 и старее) — другой протокол, поддержки не будет.
