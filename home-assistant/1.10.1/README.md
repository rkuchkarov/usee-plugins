# Home Assistant — плагин Usee

Полный паритет встроенной интеграции HASource: карточки по биндингам сущностей
(gauge / meters / status, авто-выбор), условия видимости, «—» при недоступности
с 20-секундным удержанием последнего значения, тосты из событий `usee_notify`,
staleness, heartbeat и реконнект с бэкоффом.

## Установка

Из каталога Usee («Настройки → Плагины → Каталог») или вручную: положите
`manifest.json` + `plugin.js` в
`%AppData%\PcMonitorAgent\plugins\home-assistant\1.10.1\`.

## Действия (SDK 17, агент 1.13.0)

Кнопкой в сцену («Карточки» → «Кнопка»), плиткой шторки («Действия») или жестом карточки — у каждой кнопки своя
сущность (поле «Что переключать», подсказки — из Home Assistant по набранному):

| Действие | Что делает |
|---|---|
| HA: переключить | `toggle` у света, розеток, вентиляторов, автоматизаций; у штор — открыть или закрыть; у замка — `lock.unlock` / `lock.lock` по его состоянию (службы `lock.toggle` в Home Assistant нет); с выбором «включить» / «выключить» (SDK 17) — `turn_on` / `turn_off` |
| HA: включить / выключить | `turn_on` / `turn_off` (у штор — `open_cover` / `close_cover`, у замка — `lock.lock` / `lock.unlock`) |
| HA: сцена, сценарий или кнопка | `scene.turn_on`, `script.turn_on`, `button.press` |

У замка «включено» — это «заперто»: кнопка горит на `locked`, слова на ней «Закрыто» / «Открыто» / «Отпирается» /
«Заклинило», значок — запертый или открытый замок. Дверь домофона открывает «HA: выключить» (`lock.unlock`); человек
подписывает такую кнопку своим словом («Открыть») и может включить исполнение удержанием 1 с.

Две вещи про замок домофона (у обычного электромеханического замка их нет): `lock.lock` он не умеет — запирается сам,
поэтому «HA: включить» на двери даёт ⚠ словами интеграции; а кнопка-переключатель с выбранным «выключить» может не
отправить повторное открытие, если с момента первого прошлое меньше срока, который интеграция держит состояние
«отперто». Для двери надежнее обычное нажатие («HA: выключить» без выбора «включить / выключить» у места).

Кнопка горит, когда её сущность включена (состояние — той же подпиской, что и карточки), тускнеет с причиной, когда
сущность недоступна или её нет в Home Assistant; отказ HA — знак ⚠ и его слова в журнале плагина.

## Настройки

- **Адрес сервера** — `http://homeassistant.local:8123` (или ws-URL).
- **Вход через браузер** — OAuth-вход; агент хранит refresh-токен зашифрованным
  и плагин сам обменивает его на короткий access-токен.
- **Long-lived токен** — альтернатива входу (профиль HA → Security → токены).
- **Сущности** — список биндингов; каждый: сущности (через запятую — 2+ дают
  meters), тип карточки, подпись/единица, min/max для шкалы, бейджи для status.
  Ширину карточки и условие показа задают настройки карточки Usee — как у любой
  другой (с 1.7.0 своей настройки ширины у привязки нет; прежняя переносится
  агентом в настройки карточки при первом запуске).

Тосты: событие `usee_notify` с `title`, `message?`, `kind?`
(notice|done|critical|achievement), `ttlMs?` — например из автоматизации:

```yaml
action:
  - event: usee_notify
    event_data:
      kind: done
      title: Стирка
      message: Машинка закончила
```

## Исходник

`plugin.js` — чистый ES2020 без сборки (он же и дистрибутив). Собранная копия
в реестре обязана байт-в-байт совпадать по sha256 c `index.json`.
