# Пинг сети (ping)

Плагин Usee: постоянный мониторинг задержки сети, потерь пакетов и джиттера через системную утилиту `ping`. SDK 11.

## Карточки
- **spark «график задержки» (chart)** — текущий пинг в мс и живая кривая задержки во времени (сглаживание, фиксация всплесков и лагов провайдера).
- **status «статус пинга» (status)** — сводка: текущий RTT, цветной бейдж (зелёный при стабильной связи, красный при потерях пакетов), строка диапазона «мин · ср · макс · потерь %» и джиттер.
- **message «сводка» (quote)** — крупная карточка в стиле Советника: название цели, текущий пинг крупной цифрой, джиттер (±N мс) или потери %, тон (`good` при <50 мс, `attention` при 50–100 мс, `problem` при потерях или высоком пинге).

## Цели (экземпляры)
Цели настраиваются через экземпляры: «Карточки» → «＋ Цель». Можно настроить сразу несколько независимых целей:
1. `1.1.1.1` (Cloudflare) или `8.8.8.8` (Google) — доступность внешнего интернета.
2. `192.168.1.1` — локальный шлюз/роутер (сразу видно, лагает домашний Wi-Fi/роутер или провайдер).
3. Игровой сервер или корпоративный VPN.

Поле `host` поддерживает выпадающие подсказки популярных хостов (провайдер `suggestHosts`).

## Настройки (общие)
| Ключ | Тип | Назначение |
|------|-----|-----------|
| `intervalSec` | number | Интервал проверки, 1–60 сек (по умолчанию 3 сек) |
| `timeoutMs` | number | Таймаут одного пакета в мс (по умолчанию 1000 мс) |

## Права и кросс-платформенность
Плагин объявляет строгие read-only шаблоны команд `exec`:
- `ping-win`: `ping -n 1 -w {timeout} {host}` (Windows)
- `ping-nix`: `ping -c 1 -W 1 {host}` (Linux / macOS)

Плагин автоматически определяет текущую ОС и использует правильный синтаксис системной утилиты.

## Шина значений (сущности)
Для каждого экземпляра плагин публикует сущности в шине (`ctx.entities`):
- `ping.<цель>.rtt` — текущая задержка (мс)
- `ping.<цель>.avg` — средняя задержка за окно замеров (мс)
- `ping.<цель>.loss` — процент потерь пакетов (%)
- `ping.<цель>.jitter` — средний джиттер (мс)
- `ping.<цель>.online` — доступность узла (булево)
