# Рынок (CoinGecko)

Карточки с ценами криптовалют и 24-часовым изменением. Плагин публикует две
карточки — человек ставит в раскладку сцен те, что нужны. Данные — CoinGecko
Simple Price API: бесплатно, ключ и регистрация не нужны.

## Что показывает

**`price` — «Рынок · цена» (gauge).** Цена основной монеты в выбранной валюте —
крупное число. `number` и `state` — сырая цена (шина значений, условия).
`unit` — код валюты.

**`chg` — «Рынок · 24ч» (status).** Строка изменений всех монет из списка:
`BTC -1,1%  ETH -1,2%  SOL +0,3%`. Бейдж в углу — изменение основной монеты
(`number` — это изменение как число, `state` — с знаком и %). Подпись, тикер и
валюта из настроек.

Список монет задаётся в настройке «Список монет через запятую» — id CoinGecko
(`bitcoin`, `ethereum`, `solana`, …). Монеты вне списка в статус-строке не
попадают; основная добавляется автоматически.

## Настройки

| Ключ | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `primary` | string | `bitcoin` | Основная монета (id CoinGecko) — её цена на gauge |
| `symbols` | string | `bitcoin,ethereum,solana` | Список монет через запятую |
| `currency` | select | `usd` | Валюта: `usd` / `eur` / `rub` |
| `label` | string | тикер | Подпись вместо тикера |
| `intervalMin` | number | `5` | Период опроса, мин (1–60) |

## Где живут данные и ключи

Данных нет: CoinGecko отдаёт всё по открытому адресу, ключа не требует.
Токен и пароль не нужны. Бесплатный лимит API порядка десятков запросов в
минуту — при опросе раз в 5 минут с большим запасом.

## Где взять ключ

Нигде — плагин работает сразу после установки. Если захочешь редких монет или
спрос часто, CoinGecko Pro (API-ключ) — тот же интерфейс, с ключом лимит
выше.

## Как читать ответ

`GET /api/v3/simple/price?ids=bitcoin,ethereum&vs_currencies=usd&include_24hr_change=true`
→

```json
{"bitcoin":{"usd":81349,"usd_24h_change":-1.06}, "ethereum":{"usd":2414.74,"usd_24h_change":-1.25}}
```

`<id>.<валюта>` — цена, `<id>.<валюта>_24h_change` — изменение за сутки, %.
Плагин читает ровно эти два поля на монету.

## Чего плагин НЕ делает

- Не считает прибыль/потери портфеля — он показывает рыночные цены, а не твои
  позиции.
- Не торгует и не дёргает биржу: только чтение котировок.
- Не хранит историю — кривая цены в Usee рисуется сценарием, плагин лишь
  публикует текущее значение.
