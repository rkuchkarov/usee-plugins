# Twitch (twitch)

Плагин Usee: мониторинг стримов и каналов Twitch в реальном времени. SDK 11.
Работает «из коробки» **без API-ключей** через публичный GraphQL эндпоинт Twitch, либо через официальный Twitch Helix API (по желанию).

## Карточки
- **status «Стрим» (stream)** — текущий статус канала: никнейм и количество зрителей (line1), категория/игра и время в эфире (line2), бейдж `LIVE` / `ОФФЛАЙН`, иконка эфира (`record` при стриме, `pause` при оффлайне) и название трансляции (detail).
- **spark «Зрители» (viewers)** — текущее количество зрителей (целое число или в тысячах `k`) + динамическая кривая зрителей во времени (до 90 точек в кольцевом буфере).
- **message «Сводка» (card)** — крупная карточка в стиле Советника: никнейм стримера (title), короткий заголовок (titleShort: TWITCH), число зрителей с единицей (num/unit), время эфира (num2/unit2: часы и минуты), текущая игра (expl), цветовой тон (good при онлайне, neutral при оффлайне) и статусная полоса.

## Каналы (экземпляры)
Канал настраивается у экземпляра: «Карточки» → «＋ Канал / Стример».
У каждого канала свой независимый набор карточек.

В поле `channel` можно:
1. Выбрать популярного стримера из выпадающего списка автодополнения (shroud, tarik, xQc, ibai, zxcursed, bratishkinoff, SilverName, Stray228, Nix, Evelone192, dota2ti...).
2. Ввести никнейм или логин канала, либо ссылку на канал (`twitch.tv/никнейм`) — плагин автоматически очистит и нормализует логин.
3. Искать каналы через live-автодополнение (провайдер `searchChannel`).

Все активные каналы запрашиваются одним пакетным запросом в сеть, что экономит ресурсы и трафик.

## Настройки (общие)
| Ключ | Тип | Назначение |
|------|-----|-----------|
| `intervalSec` | number | Частота обновления данных в секундах (10–300, по умолчанию 30 сек) |
| `clientId` | string | Client ID из Twitch Developer Console (опционально, для Helix API) |
| `clientSecret` | secret | Client Secret (опционально, для Helix API) |

Если ключи Helix не указаны, плагин автоматически использует публичный GraphQL эндпоинт Twitch.

## Права
- `net: ["gql.twitch.tv", "api.twitch.tv", "id.twitch.tv"]` — запросы к Twitch API.

## Шина значений (сущности)
Для каждого канала плагин объявляет сущности в шине (`ctx.entities`) для условий сцен и автоматизаций:
- `twitch.<id>.online` — статус онлайна (true/false)
- `twitch.<id>.viewers` — число зрителей
- `twitch.<id>.game` — текущая категория / игра
- `twitch.<id>.title` — название стрима
- `twitch.<id>.uptime_sec` — время трансляции в секундах
