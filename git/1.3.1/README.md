# Git (git)

Плагин Usee: текущая ветка, синхронизация с remote (ahead/behind), незакоммиченные изменения и последний коммит репозитория на дисплее. SDK 11.

## Как это работает
Git-состояние живёт в файлах `.git/` + CLI, к которым у песочницы нет прямого доступа.
Поэтому плагин использует `ctx.exec` — задекларированные в манифесте команды, которые показываются пользователю перед установкой:
```
git -C ‹repo› status --porcelain=v2 --branch    ← ветка, upstream, ahead/behind, untracked, конфликты
git -C ‹repo› diff --numstat HEAD               ← строки +добавлено / −удалено по файлам
git -C ‹repo› log -1 --format=%ct%x09%h%x09%s   ← время коммита (eventAt), хэш и тема (detail)
```
Плагин передаёт только значение `{repo}` (= настройка `repoPath`); хост проверяет, что путь остаётся под `repoPath`, и сам собирает argv (без shell).

## Карточки
- **status «ветка»** (`branch`):
  - `line1`: имя ветки (при detached HEAD — тег или короткий хэш, при конфликтах — предупреждение);
  - `line2`: дельта строк, число файлов и статус синхронизации (`+128 −42 · 6 файл.  ↑2 ↓1`), форматируется вариантами (`FitText`);
  - `badge`: `+128 −42` (акцент) при изменениях, `↑2` при непушнутых коммитах, `КОНФЛИКТ` (красный) при слиянии, `✓` если всё чисто;
  - `eventAt`: время последнего коммита (устройство само выводит «2 МИН НАЗАД» без протухания строки);
  - `detail`: короткий хэш и тема последнего коммита на широких карточках моноширинным шрифтом;
  - шина сущностей: `number` (число изменённых файлов), `is_on` (`true` при наличии изменений/конфликтов — для правил показа сцен).
- **meters «файлы»** (`files`):
  - топ-4 изменённых файла по числу строк, включая новые (`untracked`);
  - `sec`: точные изменения по файлу (`+18 −3` или `новый`);
  - `label16`: полный путь без агрессивной обрезки для карточек шире 264 px;
  - `footer`: итог по всем файлам.

## Репозитории (экземпляры)
Репозиторий — у экземпляра: «Карточки» → «＋ Репозиторий». У каждого свои карточки ветки и файлов. `repoPath` — папка репозитория (выбор папки с быстрыми пресетами проектов). Подпись на приборе задаётся в настройках карточки.

## Настройки (общие)
| Ключ | Тип | Назначение |
|------|-----|-----------|
| `intervalSec` | number | период опроса, 2–300 с (по умолчанию 10) |

## Права
`permissions: {}` (сети нет). Доступ к командам — через задекларированный блок `exec`. `{repo}` типа `path` привязан к `setting:repoPath` (не может выйти за пределы выбранной папки).

## Требования
- **Агент с SDK 11** (Usee ≥ 1.7.0).
- **`git` в PATH.**

## Локальная проверка
Агент → «Плагины» → **＋ «Плагин из папки разработки…»** → эта папка (согласиться с командами, указать папку репозитория). Или скопировать `manifest.json` + `plugin.js` в `%AppData%\PcMonitorAgent\plugins\git\1.3.1\`.
