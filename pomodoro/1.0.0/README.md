# Помодоро (pomodoro)

Плагин Usee: фокус → отдых → снова фокус, после последнего раунда — долгий отдых. SDK 15, агент 1.11.0, прошивка с
карточкой «Таймер» (`tm=1` в `VER:`, 4.0.0-dev77 и новее).

## Карточка
- **timer «Помодоро» (тип «Таймер»)** — слово фазы, остаток, полоса света (прошедшее — яркая заливка слева), точки
  раундов, «отдых в 14:30», итог дня, неделя столбиками (по размеру места). Тон фазы: готов — синий, фокус — красный,
  отдых — зелёный, долгий отдых — фиолетовый. Секунды считает прибор по своим часам: кадр уходит только при смене
  состояния.
- Старая прошивка (без «Таймера») — карточка «Активность» с остатком.

## Жесты карточки
| Жест | Действие |
|---|---|
| касание | старт, пауза, следующая фаза |
| удержание 1 с (кольцо) | сброс |
| свайп вправо | плюс минуты к фазе |
| свайп влево | пропустить фазу |

Жесты перепривязываются в окне агента: карточка → «Жесты на приборе».

## Конец фазы
Экран-уведомление во весь экран с круглыми кнопками: «+5» (продолжить ту же фазу), главная — следующая фаза, «стоп».
Отдых начинается сам через 15 с (экран заливается светом, тёмная сторона идёт справа налево); фокус — только касанием.
Конец отдыха без ответа — через 60 с экран уходит, карточка — «Начать». Старая прошивка — тост без кнопок.

## Экран отдыха
Сцена «Отдых» (предлагается при установке): карточка «Таймер» во весь экран от начала отдыха до следующего запуска
фокуса или «стоп». Во время фокуса не встаёт.

## Настройки
| Ключ | Что | По умолчанию |
|---|---|---|
| `focusMin` | фокус, мин | 25 |
| `breakMin` | отдых, мин | 5 |
| `longMin` | долгий отдых, мин | 15 |
| `rounds` | раундов до долгого отдыха | 4 |
| `plusMin` | сколько минут добавляет «плюс» | 5 |
| `notify` | уведомление во весь экран в конце фазы | вкл |
| `autoBreak` | отдых начинается сам | вкл |
| `autoFocus` | фокус начинается сам | выкл |
| `autoSec` | через сколько секунд автостарт | 15 |
| `holdSec` | сколько держится уведомление без ответа, с | 60 |

## Сущности
- `phase` — готов, фокус, отдых, долгий, ждёт, пауза;
- `left` — осталось, с.

## Состояние
Фаза, конец фазы, итог дня и недели — в `ctx.storage`; после перезапуска агента фаза идёт дальше. Фаза, кончившаяся
без агента, — уведомлением (давнее 10 минут — без него). День — по местному времени ПК.
