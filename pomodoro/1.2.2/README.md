# Помодоро (pomodoro)

Плагин Usee: фокус → отдых → снова фокус, после последнего раунда — долгий отдых. SDK 18, агент 1.15.0, прошивка с
карточкой «Таймер» (`tm=1` в `VER:`, 4.0.0-dev77 и новее); во весь экран по просьбе — 4.0.0-dev89 (`full=2`).

## Карточка
- **timer «Помодоро» (тип «Таймер»)** — слово фазы, остаток, полоса света (остаток — светлая заливка слева), точки
  раундов, «отдых в 14:30», итог дня (по размеру места). Тон фазы: готов — синий, фокус — красный,
  отдых — зелёный, долгий отдых — фиолетовый. Секунды считает прибор по своим часам: кадр уходит только при смене
  состояния.
- Жестов у карточки нет (с 1.2.2): касание раскрывает её во весь экран, как любую карточку.
- Старая прошивка (без «Таймера») — карточка «Активность» с остатком.

## Действия
Объявлены в `manifest.json` (SDK 16) — человек ставит их кнопкой в сцену или в шторку (у «старт или пауза» можно выбрать
«включить» — запустить, или «выключить» — пауза; SDK 17):
- «Помодоро: старт или пауза» — переключатель, кнопка горит, пока фаза идёт; в «Готово» и в отсчёте — следующая фаза сразу;
- «Помодоро: сброс» — **опасное**: на приборе только удержанием 1 с с кольцом;
- «плюс минуты» (в «Готово» и в отсчёте — продолжить ту же фазу), «пропустить фазу».

## Конец фазы и отдых — во весь экран
Карточка «Таймер» раскрывается во весь экран (`ctx.cards.timer.open()`, SDK 18) — тем же ходом, что по касанию: из своего
места на сцене, а без места — проявляется посередине.
- **Фокус дотикал** — карточка раскрывается, в ней отсчёт «До отдыха 0:15» тоном отдыха (свет уходит справа налево).
  Отсчёт кончился — в ней же идёт отдых. Без автостарта — «Готово»; без ответа 60 с она сворачивается и ждёт на месте.
- **Отдых** — во весь экран до запуска фокуса.
- **Отдых кончился** — «Готово» во весь экран; без ответа 60 с — «Начать», всё так же во весь экран.
- **Фокус** (кнопкой или автостартом) и **сброс** сворачивают карточку в её место.
- Свернуть руками — смахнуть вниз; до конца следующей фазы она сама не раскроется.
- «Во весь экран» выключен — карточка остаётся на месте, отдых начинается сразу. Прошивка без `full=2` — тоже на месте.

## Настройки
| Ключ | Что | По умолчанию |
|---|---|---|
| `focusMin` | фокус, мин | 25 |
| `breakMin` | отдых, мин | 5 |
| `longMin` | долгий отдых, мин | 15 |
| `rounds` | раундов до долгого отдыха | 4 |
| `plusMin` | сколько минут добавляет «плюс» | 5 |
| `notify` | во весь экран: конец фазы и отдых | вкл |
| `autoBreak` | отдых начинается сам | вкл |
| `autoFocus` | фокус начинается сам | выкл |
| `autoSec` | через сколько секунд автостарт (отсчёт в карточке) | 15 |
| `holdSec` | сколько ждать ответа после конца фазы, с | 60 |

## Сущности
- `phase` — готов, фокус, отдых, долгий, ждёт, пауза;
- `left` — осталось, с.

## Состояние
Фаза, конец фазы, итог по дням — в `ctx.storage`; после перезапуска агента фаза идёт дальше. Фаза, кончившаяся
без агента, — как обычно (давнее 10 минут — тихо «Начать», без отдыха и без «во весь экран»). День — по местному времени ПК.
